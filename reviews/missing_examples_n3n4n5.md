# N3/N4/N5 缺失例句清单

## N3 (48 条)

1. **〜ばかりに**
   - 含义：只因……（负面结果）
   - 接续：动词普通形/名詞 + ばかりに

2. **〜だけに**
   - 含义：正因为……
   - 接续：动词普通形/名詞 + だけに

3. **〜だけあって**
   - 含义：不愧……
   - 接续：动词普通形/名詞 + だけあって

4. **〜だけのことはある**
   - 含义：不愧……
   - 接续：动词普通形/名詞 + だけのことはある

5. **〜さえ〜ば**
   - 含义：只要……就……
   - 接续：名詞 + さえ + 动词ば形

6. **〜すら**
   - 含义：连……都（书面）
   - 接续：名詞 + すら

7. **〜でも**
   - 含义：即使是……也……
   - 接续：名詞 + でも

8. **〜だに**
   - 含义：甚至连……都不（书面）
   - 接续：名詞 + だに + 动词ない

9. **〜ながら**
   - 含义：虽然……但是……
   - 接续：动词ます形/名詞 + ながら

10. **〜つつ**
   - 含义：一边……/虽然……
   - 接续：动词ます形 + つつ

11. **〜ものと思われる**
   - 含义：被认为……
   - 接续：动词普通形 + ものと思われる

12. **〜ものと考えられる**
   - 含义：被认为……（更正式）
   - 接续：动词普通形 + ものと考えられる

13. **〜とされている**
   - 含义：被认为……/人们认为……
   - 接续：动词普通形 + とされている

14. **〜と言われている**
   - 含义：人们说……
   - 接续：动词普通形 + と言われている

15. **〜に違いない**
   - 含义：一定……
   - 接续：动词普通形/名詞 + に違いない

16. **〜に極まっている**
   - 含义：极其……
   - 接续：名詞/ナ形容詞 + に極まっている

17. **〜の至りだ**
   - 含义：……至极
   - 接续：名詞 + の至りだ

18. **〜というものだ**
   - 含义：所谓……
   - 接续：动词普通形/名詞 + というものだ

19. **〜ということだ**
   - 含义：也就是说……/据说……
   - 接续：动词普通形/名詞 + ということだ

20. **〜ということはない**
   - 含义：不必……
   - 接续：动词辞書形 + ということはない

21. **〜からには**
   - 含义：既然……就……
   - 接续：动词普通形/名詞 + からには

22. **〜以上**
   - 含义：既然……就……
   - 接续：动词普通形/名詞 + 以上

23. **〜上**
   - 含义：在……方面/上
   - 接续：动词た形/名詞 + の + 上

24. **〜上に**
   - 含义：而且……
   - 接续：动词普通形/名詞 + 上に

25. **〜一方**
   - 含义：另一方面……
   - 接续：动词普通形 + 一方

26. **〜反面**
   - 含义：反面……
   - 接续：动词普通形/名詞 + の反面

27. **〜かわりに**
   - 含义：代替……/虽然……但是……
   - 接续：动词普通形/名詞 + かわりに

28. **〜代わりに**
   - 含义：代替……/作为交换……
   - 接续：动词普通形/名詞 + 代わりに

29. **〜反面**
   - 含义：相反地……
   - 接续：动词普通形/名詞 + 反面

30. **〜反面**
   - 含义：与……相反
   - 接续：动词普通形/名詞 + 反面

31. **〜にしたがって**
   - 含义：随着……/按照……
   - 接续：动词辞書形/名詞 + にしたがって

32. **〜に伴って**
   - 含义：随着……
   - 接续：动词辞書形/名詞 + に伴って

33. **〜に応じて**
   - 含义：根据……
   - 接续：名詞 + に応じて

34. **〜に反して**
   - 含义：与……相反
   - 接续：名詞 + に反して

35. **〜に基づいて**
   - 含义：基于……
   - 接续：名詞 + に基づいて

36. **〜を皮切りに**
   - 含义：以……为开端
   - 接续：名詞 + を皮切りに

37. **〜を始め**
   - 含义：以……为首
   - 接续：名詞 + を始め

38. **〜をはじめとする**
   - 含义：以……为首的……
   - 接续：名詞 + をはじめとする

39. **〜にわたって**
   - 含义：历时……/遍及……
   - 接续：名詞 + にわたって

40. **〜を通じて**
   - 含义：通过……
   - 接续：名詞 + を通じて

41. **〜を通して**
   - 含义：通过……/整个……
   - 接续：名詞 + を通して

42. **〜を込めて**
   - 含义：饱含……
   - 接续：名詞 + を込めて

43. **〜をもって**
   - 含义：以……/用……
   - 接续：名詞 + をもって

44. **〜かたわら**
   - 含义：一边……一边……
   - 接续：名詞 + のかたわら

45. **〜がてら**
   - 含义：顺便……
   - 接续：动词ます形/名詞 + がてら

46. **〜ついでに**
   - 含义：顺便……
   - 接续：动词た形/名詞 + のついでに

47. **〜かねる**
   - 含义：难以……
   - 接续：动词ます形 + かねる

48. **〜がたい**
   - 含义：难于……
   - 接续：动词ます形 + がたい

## N4 (40 条)

1. **〜にする**
   - 含义：决定……/选择……
   - 接续：名詞 + にする

2. **〜になる**
   - 含义：变成……/成为……
   - 接续：名詞/ナ形容詞 + になる

3. **〜に決まる**
   - 含义：定为……
   - 接续：名詞 + に決まる

4. **〜ように言う**
   - 含义：让/请……做……
   - 接续：动词辞書形/ナイ形 + ように言う

5. **〜ようになる**
   - 含义：变得能够……
   - 接续：动词可能形/ナイ形 + ようになる

6. **〜ことになる**
   - 含义：（客观）决定/变成……
   - 接续：动词辞書形 + ことになる

7. **〜ことにする**
   - 含义：决定……
   - 接续：动词辞書形 + ことにする

8. **〜ことにしている**
   - 含义：养成……习惯
   - 接续：动词辞書形 + ことにしている

9. **〜ことになっている**
   - 含义：规定……/预定……
   - 接续：动词辞書形 + ことになっている

10. **〜つもりだ**
   - 含义：打算……
   - 接续：动词辞書形/ナイ形 + つもりだ

11. **〜つもりはない**
   - 含义：不打算……
   - 接续：动词辞書形/ナイ形 + つもりはない

12. **〜つもりで**
   - 含义：以……心态/当作……
   - 接续：动词辞書形/ナイ形 + つもりで

13. **〜ところに**
   - 含义：正当……时
   - 接续：动词ている/辞書形 + ところに

14. **〜ところへ**
   - 含义：正当……时（有人来了）
   - 接续：动词ている/辞書形 + ところへ

15. **〜ところを**
   - 含义：正在……的时候（被打扰）
   - 接续：动词ている + ところを

16. **〜たばかり**
   - 含义：刚刚……
   - 接续：动词た形 + ばかりだ

17. **〜たところ**
   - 含义：刚……之后
   - 接续：动词た形 + ところ

18. **〜かける**
   - 含义：做到一半/刚开始
   - 接续：动词ます形 + かける

19. **〜かけだ**
   - 含义：……了一半的状态
   - 接续：动词ます形 + かけだ

20. **〜っこない**
   - 含义：不可能……（口语）
   - 接续：动词ます形 + っこない

21. **〜わけにはいかない**
   - 含义：不能……
   - 接续：动词ない形 + わけにはいかない

22. **〜わけがない**
   - 含义：不可能……
   - 接续：动词普通形/名詞 + わけがない

23. **〜わけではない**
   - 含义：并非……
   - 接续：动词普通形/名詞 + わけではない

24. **〜わけだ**
   - 含义：当然……/也就是说……
   - 接续：动词普通形/名詞 + わけだ

25. **〜というわけだ**
   - 含义：也就是说……
   - 接续：简体句 + というわけだ

26. **〜ものか**
   - 含义：怎么会……呢（强烈否定）
   - 接续：动词辞書形 + ものか

27. **〜ものだから**
   - 含义：因为……嘛（辩解）
   - 接续：动词普通形/名詞 + ものだから

28. **〜ものではない**
   - 含义：不应该……
   - 接续：动词辞書形 + ものではない

29. **〜ことか**
   - 含义：多么……啊
   - 接续：动词普通形/ナイ形 + ことか

30. **〜ことだから**
   - 含义：因为毕竟是……
   - 接续：名詞 + のことだから

31. **〜どころか**
   - 含义：别说……就连……
   - 接续：动词普通形/名詞 + どころか

32. **〜どころではない**
   - 含义：不是……的时候
   - 接续：动词辞書形/名詞 + どころではない

33. **〜なんか**
   - 含义：……之类的（轻蔑）
   - 接续：名詞 + なんか

34. **〜なんて**
   - 含义：竟然……/……什么的
   - 接续：动词普通形/名詞 + なんて

35. **〜くらいなら**
   - 含义：与其……不如……
   - 接续：动词辞書形/名詞 + くらいなら

36. **〜ばかりでなく**
   - 含义：不仅……而且……
   - 接续：动词普通形/名詞 + ばかりでなく

37. **〜のみならず**
   - 含义：不仅……（书面）
   - 接续：名詞/动词普通形 + のみならず

38. **〜あまり**
   - 含义：由于过度……
   - 接续：名詞/动词普通形 + のあまり

39. **〜あまりの**
   - 含义：由于太……
   - 接续：あまりの + 名詞

40. **〜ないこともない**
   - 含义：也不是不……
   - 接续：动词ない形 + ないこともない

## N5 (2 条)

1. **〜など**
   - 含义：……等等
   - 接续：名詞 + など

2. **〜くらい/ぐらい**
   - 含义：大约……/像……那样
   - 接续：数量/动词普通形 + くらい/ぐらい
